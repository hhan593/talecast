### 屏幕映射

## 2. 四功能（各自 PR）

| # | 功能 | 技术要点 | 注意 |
| --- | --- | --- | --- |
| F-1 | 后台/锁屏播放 | 引入 react-native-track-player（新依赖，PR 说明：锁屏/媒体通知需 MediaSession，expo-audio 不提供）；AudioPlayer 端口新增 track-player 适配；播放速度（0.8-2.0×）走播放端速率 | **Expo Go 不含该原生模块**——需安装 v0.2.1+ dev APK 或 EAS dev build |
| F-2 | TTS 参数调节 | 绑定级 prosody（rate/pitch/volume）存 binding.providerParamsJson → 已在 input_hash 构成内，参数变更自动失效旧缓存；SSML `<prosody>` 注入；UI 在绑定页 | 播放端倍速另由 F-1 提供（即时、免重生成） |
| F-3 | 音频导出分享 | 段为同参 MP3 → 字节顺序拼接即合法整章 MP3；expo-sharing 分享；仅 done 段可导出 | 无需 ffmpeg；文件落 cache 再 share |
| F-4 | 阅读增强 | 迁移 v5：bookmarks 表；阅读器字号设置（settings）；全文搜索（章节内→全书两级） | 搜索走已有字符偏移体系 |
