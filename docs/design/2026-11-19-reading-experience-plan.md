# 计划书：阅读体验对齐市面主流（听读双模阅读器）

文档状态：待确认后执行
日期：2026-11-19
调研基准：Moon+ Reader Pro（功能最全的本地阅读器）、微信读书（出版书排版/AI 朗读）、
起点读书（网文追更/自动连播）、Legado 阅读 3.0（开源本地+书源+净化，21K★）
定位差异：TaleCast 的差异化是**听读双模**——TTS 章节音频（预生成）与手动阅读共享同一
字符偏移体系，"边听边读、听到哪跟到哪"。对标时凡与该定位冲突的功能一律不做（见 §7）。

## 2. 分期（RE-1 → RE-4）

### RE-1 排版与主题系统（P0，v0.6.0）
1. **主题四套**：纸感（默认，现墨韵纸感亮色）/ 暖黑（现夜读）/ 护眼绿（#C7E3CE 底）/
   纯白；跟随系统 + 手动覆盖（阅读工具栏主题循环按钮）。
2. **排版面板**：字号四档（已有）+ 行距三档（1.5/1.7/1.9×）+ 页边距三档（窄/标准/宽）+
   段间距两档。全部进 `reading_state`（迁移 v6 已有 reader_mode/font_size，扩列
   line_spacing/page_margin）。
3. **metrics 联动**：排版参数全部进 `PageMetrics`（charsPerLine/linesPerPage 随行距边距变化），
   重算后按页首偏移回位——分页确定性体系直接复用。
4. **沉浸模式**：阅读工具栏自动隐藏（3 秒无操作），点击呼出；状态栏隐藏。
5. 验收：四主题 × 四字号 × 三行距全组合下分页合同测试通过（切片拼接即全文）。

### RE-2 听书补全（P0，v0.6.0）
1. **自动连播**：章末（queue done）自动取下一章 done 任务续播；下一章未生成时停止并提示。
   开关持久化（settings `auto-next-chapter`，默认开）。
2. **睡眠定时器**：15/30/60/90 分钟，倒计时结束暂停播放（播完当前段再停，不打断段中）；
   阅读工具栏月亮按钮。
3. **耳机 Next/Prev**：远程控制事件映射跳段（F-1 已注册 Capability，补事件处理）。
4. 验收：连播跨章无重叠/无断档；定时器暂停后手动恢复播放正常；耳机按键响应。

### RE-3 净化与搜索增强（P1，v0.6.x）
1. **替换净化**（Legado 招牌）：规则 = 正则对列表（find/replace，本地 TXT 场景去页眉广告）。
   **来源不动**——规则存 settings/工程维度，阅读与导出时应用（展示层变换，
   与"原文不可变"原则一致）。默认内置两条常见页眉页脚规则模板。
2. **搜索增强**：结果上限 100 条 + "结果过多"提示；搜索范围限定当前章节选项。
3. 验收：净化规则对页眉广告样例生效；来源文件字节不变。

### RE-4 沉浸与进阶（P1-P2，v0.7.0）
1. **自动滚屏**：滚动模式下的匀速自动滚动（速度 3 档，触摸暂停）。
2. **EPUB 封面图**：manifest cover 提取 → 沙盒存储 → 书架真实封面。
3. **进度百分比 + 拖章进度条**：阅读/播放双进度。
4. **阅读统计**：每日阅读时长与字数（本地记录，无上传）。
5. **数据备份**：书架+偏好导出 JSON（文件分享），导入恢复。

## 3. 技术要点

- 主题：`global.css` 定义 CSS 变量集 + tailwind token 映射（现有 paper/card 体系扩展为
  theme 桶：theme-paper/theme-night/theme-green/theme-white），阅读工具栏循环，settings 持久化。
- 排版：`PageMetrics` 增 lineSpacing/pageMargin 字段（ paginate 确定性不变）。
- 连播：playback 服务 onPlaybackEnd 分支——queue done 且 autoNext 开启 →
  取下一章 done 任务续播（generationStore.listJobsByChapter 顺序取）。
- 定时器：playback 服务内部定时（Date.now 差值），暂停走现有 pause；设置持久化于内存即可。
- 净化：`src/domain/replacement.ts` 纯函数（规则列表 + 文本 → 净化文本），规则存 settings JSON。
- 搜索上限：searchBook 增加 limit 参数（默认 100，超出返回 hasMore 标记）。

## 4. 验收汇总

- 主题/排版全组合下分页合同测试（拼接即全文）通过；切换主题排版后位置按偏移回位。
- 连播：3 章连播跨章无断档；关闭开关后章末停止。
- 定时器：到期暂停且当前段完整；恢复播放正常。
- 净化：规则命中样例去除广告行；来源 sha256 不变。

## 5. 不做清单

仿真真卷页 Skia（v0.4.x 增强）、音量键翻页（需原生模块）、竖排、E-ink 模式、
PDF/DjVu、社交笔记/划线分享、在线书城聚合（书源引擎执行调度后置，见 phase2-plan §6）。
