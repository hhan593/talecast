# v0.8.0 交互补齐与排版进阶（设计说明）

> 日期：2026-11-20
> 范围：P1 交互补齐包 + P2 排版进阶包 + R3 遗留 UI 缺口（搜索/书签列表）

## 1. 背景

v0.7.0 全量门禁绿但存在两类问题：**代码实态问题**（无 ErrorBoundary、
playback 40 行重复、组件层零测试补充不足）与**主流阅读器交互差距**
（读器内无上下章、无进度条、菜单生硬、搜索/书签只有服务层没有 UI）。
本版一次性补齐"每天用得到"的体感差距。

## 3. 分页模型扩展（domain/reader）

- `PageMetrics` 新增可选 `lineHeightPx / paragraphSpacingPx / indentChars`；
  提供前两者时切换像素预算打包（段边界计间距），否则保持旧行为（整数行打包）。
- `toSegments`：`indentChars` 使段首行少排 N 字；段记录 `endsLine` 供间距判据。
- 不变量保持：页切片拼接 = 全文、页边界落在段边界、同输入同分页。
- 排版变化后页定位用**当前所在页首**（不回跳到进入时偏移）；跨章切换才用恢复偏移。

## 4. 顺手修复

- 点击分区的当前页号从未同步（翻页点击永远按第 0 页算）：slide 模式接
  `onPageSelected`，cover/curl 由 onScroll listener 同步。
- 滚动模式无点击呼出菜单（菜单 3 秒隐藏后永久失踪）：FlatList 包 Touchable。
- 菜单改为悬浮 overlay：显隐不再改变正文容器高度 → 不再触发重分页跳动。
- PagerView 窗口化渲染（当前页 ±3 页）：长章首屏不再渲染全部页。
- `types.ts` 重复的 BookmarkRecord 导出合并；阅读器补上 pageTurnStyle 循环按钮。

## 5. 测试

- domain/reader：段间距像素预算（同页计间距/跨页不计）、缩进少排、空行计行、拼接不变量（+4）
- services/generation：预生成（触发/跳过/开关关/末章）（+4）
- services/playback：渐弱序列 [1,0.8,…,0.2,1]（fake timers）、取消渐弱中断、播放触发预生成（+3）
- 共 112 测试全绿；typecheck 0；架构守卫 3 规则通过。

- lint 不在 CI 门禁（存量 49 error 集中在 hooks 的 react-compiler 规则），本次仅修
  属于改动面的部分（重复导出、JSX 裸引号）；hooks 规则类债务另行处理。
